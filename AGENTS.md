# AGENTS.md

This file defines the global working rules for any agent/assistant in this workspace.

## Mandatory rules

1. **Never create commits without the user's explicit prior permission.**
2. **Always ask the user before deleting files, code, or configuration.**
3. **If deletion is proposed, explain the need and expected impact before making the change.**
4. **Focus strictly on the requested objective.**
5. **Do not apply extra, unsolicited changes, even if they may improve code quality.**

## **Priority**

If there is any conflict between optional technical decisions and these rules, this document and the user's instruction take precedence.
